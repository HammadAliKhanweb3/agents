# AI Agents Repository

This repository contains sample implementations of simple AI agents and graph search algorithms. It is organized by agent type and algorithm so you can explore and run each example separately.

## Repository Structure

- `DFS_and_BFS/`
  - `01_dfs_and_bfs.py` - Basic graph traversal example using depth-first search and breadth-first search.
  - `02_dfs_and_bfs.py` - Another example with a different graph or traversal variation.
  - `03_dfs_and_bfs.py` - Additional traversal example or enhancement.

- `simple-reflex-agent/`
  - `simple-reflex-agent.py` - Implementation of a simple reflex agent that chooses actions based only on the current percept.

- `table-driven-agent/`
  - `table-driven-agent.py` - Implementation of a table-driven agent that uses a lookup table of percept sequences to actions.

## How to Use

1. Open the repository in your Python development environment.
2. Run the desired script with Python.

Example:

```bash
python DFS_and_BFS/01_dfs_and_bfs.py
```

or:

```bash
python simple-reflex-agent/simple-reflex-agent.py
```

## Notes

- Each folder contains a self-contained example.
- The examples are written in Python and should run using a standard Python 3 interpreter.
- The repository is organized to help you compare basic agent designs and graph search techniques.
